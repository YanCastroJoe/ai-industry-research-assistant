## 故障恢复场景

构造 `retrieve_documents` 第一次调用发生瞬时故障、第二次恢复的场景：Runtime 记录 1 次 `retrying`，第 2 次尝试成功，后续引用校验通过。另有自动化测试验证格式化工具失败后，新的 Run 从序号 5 的检查点恢复，未重复执行检索、事实抽取、语义理解和文档生成步骤。

## MCP 集成验证

通过官方 MCP Python SDK 的 stdio 传输完成：

1. ClientSession 初始化；
2. `list_tools` 发现 `retrieve_project_evidence` 与 `verify_document_citations`；
3. 将远程检索工具映射到 Tool Registry；
4. 通过 `call_tool` 返回结构化 Evidence；
5. Agent Runtime 完成后续文档生成与引用校验。

## 口径限制

- 固定集规模较小且为合成任务，只用于回归，不代表真实业务泛化效果。
- 工具选择指标只评估风险清单与汇报大纲两个可选交付工具。
- Citation Pass Rate 仅验证 ID 可追溯性；Rule Content Quality Pass Rate 是确定性规则检查，覆盖负责人/日期保留、风险覆盖、分类和汇报选材，二者均不代表完整语义蕴含或生产准确率。
